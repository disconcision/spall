Agent chatterStratum · reference board for a sidebar where many agents and robot workers talk at once · 27 Oct 2026

Panels P1–P10 are original mock-ups at real sidebar width (312 px), drawn in the game’s palette and 3×5 font. References R1–R22 are what each one borrows from, with links. Point at favourites by code (“P4 gloss + P5 holes, less of P6”).
Chat zoom = city zoomThe creative brief says coarse-graining is delegation. The sidebar should follow suit: far out, talk is texture; up close, it’s words. P1 P9
One colour grammarBot talk is coloured by role, using the game’s data-wire strand colours. The same colours run through glyph strings, blocks, nested plans and patches. P10
Plans are violet holesA sub-agent is a filled hole. A hole no bot can fill climbs up to you as a question: Hazel’s typed holes as the delegation protocol. P5
Gloss, don’t translateBots never speak English. An aligned gloss row is their subtitle, and higher-order talk is drawn in the game’s own cables and ties. P4 P6

R1

Uiua

uiua.orgpadprimitivesrepo

LooksA stack-based array language written in single Unicode glyphs (⊂ ⇌ ≡ ⊞). The site colours each glyph by how many arguments it takes: green for one (#95d16a), blue for two (#54b0fc), yellow and purple for modifiers (#f0c36f, #cc6be9), pale grey for stack shuffles.

BorrowColour by role, so a glyph string reads at a glance, even blurred. One glyph means one thing. Recoloured here with Stratum’s strand palette, not copied.

R2

APL and BQN

APLBQNBQN primitives

LooksDense one-character primitives with shapes that hint at their meaning. BQN’s docs colour by syntactic role: functions green, 1-modifiers plum, 2-modifiers olive-gold, values grey.

BorrowA small, closed alphabet where shape carries meaning (⊓ lift / ⊔ drop, ⟦ ⟧ quote). Role, not word, decides the colour.

R3

colorForth

colorforth.github.ioprimer

LooksChuck Moore’s Forth, where a word’s colour replaces punctuation: red defines, green compiles, yellow executes, white is a comment.

BorrowColour is the syntax. That’s why the firehose still carries information when no text is readable, and why Z0/Z1 zooms work.

R4

Ragged Blocks

Cohen & Chugh, UIST ’25 (arXiv)

LooksNested code drawn as “rocks”: rectilinear polygons with irregular borders that hug each line of text. Every syntax node gets a border and padding, but the layout stays close to plain text, unlike nested rectangles.

BorrowThe violet plan blocks in P5 use a tiny pixel version: each node’s rock is a dilated row-hull of its children, with a 1 px emboss and a depth tint.

R5

Hazel: holes, livelits, projectors

hazel.orglive editorprojectors referencelivelits, PLDI ’21

LooksA structure editor in which incomplete programs have typed holes and still run. Livelits fill holes with live GUIs. Projectors swap a term for a view: fold to “…”, checkbox, slider, text area, type, card, colour, table.

BorrowHoles as the unit of delegation, with open-hole counts on threads. Projectors (slider, checkbox, fold) inside plans. The voice note as a projection of its transcript.

R6

tylr

repoGradual Structure Editing with Obligations, VL/HCC ’23Syntactic Completions with Material Obligations, OOPSLA ’25

LooksTile-based structure editing: you type text, but tokens behave as tiles, and missing pieces are shown as explicit obligations instead of errors.

BorrowAn unfinished plan isn’t broken. It shows what it still owes, and the “▢ 2 open holes” counters come from this.

R7

Typed holes as LLM context

Blinn, Li, Kim, Omar, OOPSLA ’24 (arXiv)

LooksNot a visual reference. The paper uses a hole’s expected type and typing context to tell a language model what code is needed.

BorrowA hole is a complete brief for a sub-agent: its type is the task, and its context is what the agent gets told. So handing F-2 a hole is enough, and a hole is what you see when an agent spawns.

LooksA projectional editor for a Haskell-like language. Live evaluation results and type errors are annotated right under each subexpression.

Scratch blocks

Block Shapes (wiki)Blocks

LooksHat blocks with a rounded top, stack blocks with a notch and a bump, C blocks that wrap others, round reporters, hexagonal booleans, coloured by category.

BorrowShape is grammar, so even a pixel-scale block stack reads as a program. Here the categories are the glyph roles.

Snap!

LooksScratch-style blocks, but a grey ring around a block makes it a value (lambda). Nested blocks of the same category alternate light and dark (zebra).

BorrowThe ringed block T-tie hands over, a program passed as a thing. Zebra lightening for nested violet C blocks.

LooksObject boxes joined by patch cords. Audio signal cords have a yellow-and-black striped look, distinct from Max message cords.

Blender nodes

manual: nodes

LooksRounded nodes with coloured header strips. Sockets on the sides are coloured by data type, joined by smooth curves. (Socket colours from memory; the docs block scripted fetches.)

BorrowSide ports instead of Max’s top and bottom ports, so wires can hang and droop between nodes the way Stratum cables do.

R14

Orca

hundredrabbits/Orcaesolangs

LooksA black grid of dots in which every letter is an operator. Operators sit on teal blocks (#72dec2), the cursor is an amber block (#ffb545), and the whole program runs every frame.

BorrowOperators as inverted blocks and an amber “now” cell in the drone’s route grid. A whole crew’s schedule could be one live grid.

toontalk.comWikipedia

R19

Pictorial Janus

Janus (Wikipedia)Kahn & Saraswat, “Complete Visualizations of Concurrent Programs and Their Executions”, 1990

LooksA visual form of a concurrent constraint language: agents and messages are drawn as nested closed contours and links, and running the program animates the picture.

BorrowAgents as shapes that pass messages. The longer-term direction: higher-order exchanges as small animated pictures, not text.

Opus Magnum7 Billion Humans

LooksOpus Magnum gives each arm its own timeline row of instruction symbols. 7 Billion Humans has a crowd of identical workers running one visual program, often chaotically.

Interlinear gloss

Leipzig Glossing Rules

LooksThe linguistics convention: the original line, then a word-by-word aligned gloss in small capitals, then a free translation.

BorrowBot speech gets glossed, never translated: an aligned 3×5 caption under each glyph, toggled from the header.
