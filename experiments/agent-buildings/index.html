Agent buildings

Six building types an agent designed from one-line player briefs: it wrote each spec and its game logic, ran the validator, rendered with the unmodified concept-render kit, looked at the result and redrafted. 22 drafts in 36 minutes. The finding: spec, validator and fixed renderer give consistency and sound game logic for free, but not, by themselves, a good look; that took kit extensions.
